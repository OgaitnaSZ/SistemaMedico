# AppSistemaMedico

Sistema Médico UI es una plataforma web diseñada para la gestión integral de pacientes e historias clínicas. 
Permite a los profesionales de la salud registrar y acceder rápidamente a datos clínicos como consultas médicas, tratamientos realizados, archivos adjuntos (como estudios o análisis) y datos personales del paciente. 

El sistema está orientado a médicos que buscan una herramienta ágil, intuitiva y segura para llevar un seguimiento completo y organizado de sus pacientes.

## Tecnologías usadas
- Angular (Frontend)
- Express (Backend)
- MongoDB (Base de Datos)
- TailwindCSS (Estilos)

## Dependencias adicionales de Angular
- **ngx-infinite-scroll** - Scroll infinito en tablas de pacientes
- **ng2-charts** - Visualización de gráficos estadísticos.
- **snack-bar** - Visualización de mensajes.
- **xlsx** - Importación y exportación de archivos Excel
